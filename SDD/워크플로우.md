## 워크플로우 

1. 화면의 영역은 로고/메뉴바/메인화면/팝업화면으로 구성된다. 
2. 초기 접속 시 감상평 조회 메뉴가 Default로 오픈된다. 
3. 메뉴바는 감상평, 영화정보로 구성된다. 각 메뉴 버튼을 클릭하면 해당 메뉴로 이동된다. 
4. 감상평 조회 메뉴에서 감상평 등록 버튼을 클릭하면 감상평 작성 팝업이 메인화면 위에 출력된다. 
5. 감상평 작성 후 저장하면 Supabase Database(`reviews` 테이블)에 저장되고, 포스터 이미지는 Supabase Storage에 업로드된다.
6. 감상평 작성이 완료되면 팝업이 사라지고, 감상평 조회 화면이 한번 더 조회된다. 
7. 조회 된 감상평 리스트 중 대상을 선택하여 클릭하면 해당 감상에 대한 정보를 불러와 감상평 팝업에 출력된다. 
8. 감상평 팝업의 수정 버튼을 클릭하면 감상평 작성 모드로 변경되고, 저장 시 수정내용이 반영된다.
9. 감상평 조회 결과의 각 row의 수정 버튼을 누르면 감상평 팝업가 수정모드로 활성화되고, 삭제 버튼 클릭 시 삭제 확인 후 해당 row를 삭제한다.
10. 영화정보조회 화면은 현재 날짜 기준으로 개봉 중인 영화를 표시한다. 
11. 영화정보조회 화면에서 개봉 중인 영화 리스트 중 하나의 셀을 클릭하면 영화에 대한 정보가 출력되는 팝업이 출력된다. 
12. 감상평 메뉴는 로그인이 필요하다. 비로그인 상태에서 감상평 메뉴를 클릭하면 로그인/회원가입 화면이 표시되며, 영화정보 메뉴는 비로그인 상태에서도 접근할 수 있다. (SDD/회원가입로그인기능명세.md 참고)
13. 헤더(메뉴바 영역)에는 로그인 상태에 따라 로그인/로그아웃 상태가 표시된다. 로그인 성공/회원가입 완료 시 감상평 조회 화면으로 이동하고, 로그아웃 시 감상평 메뉴가 열려 있었다면 로그인 화면으로 전환된다.
