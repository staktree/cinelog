## 워크플로우 

1. 화면의 영역은 로고/메뉴바/메인화면/팝업화면으로 구성된다. 
2. 로그인하지 않은 상태로 감상평 조회 화면(메인화면)에 접속하면 로그인 화면으로 이동한다.
   영화정보 조회 화면은 로그인 없이도 열람할 수 있다.
3. 로그인 후 초기 접속 시 감상평 조회 메뉴가 Default로 오픈된다. 
4. 감상평 조회 메뉴에서 감상평 등록 버튼을 클릭하면 감상평 작성 팝업이 메인화면 위에 출력된다. 
5. 감상평 작성 후 저장하면 Supabase reviews 테이블에 로그인한 사용자 소유로 저장된다. 
6. 감상평 작성이 완료되면 팝업이 사라지고, 감상평 조회 화면이 한번 더 조회된다. 
7. 조회 된 리스트 중 대상을 선택하여 클릭하면 해당 감상에 대한 정보를 불러와 감상평 팝업에 출력된다.
8. 감상평 팝업의 수정 버튼을 클릭하면 감상평 작성 모드로 변경되고, 저장 시 수정내용이 반영된다.
9. 헤더의 로그아웃 버튼을 클릭하면 로그아웃되고 로그인 화면으로 이동한다.
