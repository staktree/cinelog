## 회원가입/로그인 기능 명세

1. 인증은 Supabase Auth의 이메일/비밀번호 방식만 사용한다. (소셜 로그인 없음)
2. 비로그인 상태에서 감상평 메뉴에 진입하면 감상평 조회 화면 대신 로그인/회원가입 화면이 표시된다.
3. 영화정보 메뉴는 로그인 여부와 관계없이 항상 접근 가능하다.
4. 회원가입 시 이메일, 비밀번호, 비밀번호 확인을 입력받는다.
   - 이메일은 형식 검증(예: `example@domain.com`)을 통과해야 한다.
   - 비밀번호는 8자 이상이어야 한다.
   - 비밀번호와 비밀번호 확인 값이 다르면 저장 불가 알림을 표시한다.
5. 이미 가입된 이메일로 회원가입을 시도하면 에러 메시지를 표시한다.
6. 회원가입이 완료되면 자동으로 로그인 처리하고 감상평 조회 화면으로 이동한다.
   (Supabase 프로젝트의 이메일 확인(Confirm email) 설정을 끈 상태를 전제로 한다)
7. 로그인 화면에서 이메일, 비밀번호를 입력하여 로그인한다.
8. 이메일 또는 비밀번호가 일치하지 않으면 에러 메시지를 표시한다.
9. 로그인에 성공하면 세션을 유지하고 감상평 조회 화면으로 이동한다.
10. 로그인 상태에서는 헤더(로고/메뉴바 영역)에 로그아웃 버튼이 표시된다.
11. 로그아웃 버튼을 클릭하면 세션이 종료되고, 감상평 메뉴가 열려 있었다면 로그인 화면으로 전환된다.
12. 새로고침/재접속 시에도 Supabase 세션이 유효하면 로그인 상태가 유지된다.
