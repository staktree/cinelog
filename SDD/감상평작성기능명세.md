##감상평 작성 기능 Spec

1. 감상평은 제목, 평점, 감상평, 한줄평,작성일자으로 이루어짐. 
2. 제목은 최대 30자, 평점은 1~5의 숫자(0.5단위로 부여 가능함),
    감상평은 최대 2000자, 한줄평은 최대 100자
3. 각 감상평은 감상평ID로 구분한다(감상평 ID가 PK 역할 수행)
4. 감상평ID는 YYMMDD00001 형식으로 생성 날짜와 5자리 숫자로 구성된다.  
5. 감상평ID는 (작성자와 무관하게 전체 기준으로) 중복될 수 없으며,
   현재 날짜 YYYYMMDD + 당일 마지막에 생성된 감상평의 순번 + 1로 발번된다.
   동시에 여러 요청이 들어와도 순번이 중복되지 않도록 서버(DB)에서 원자적으로 발번한다.
6. 최초 생성되는 감상평ID의 숫자부분은 00001이다. 
7. 감상평 작성 화면에서 각각의 데이터를 입력한다. 
8. 감상평은 로그인한 사용자(user_id)에게 귀속된다.
9. 저장 버튼을 클릭하면 Supabase(Postgres) reviews 테이블에 저장된다.
10. 저장 위치: Supabase 프로젝트의 reviews 테이블 (기존 root/savedData/review 파일 저장 방식은 폐기한다)
