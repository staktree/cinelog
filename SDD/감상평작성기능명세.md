##감상평 작성 기능 Spec

1. 감상평은 제목, 평점, 감상평, 한줄평,작성일자, 이미지BLOB으로 이루어짐. 
2. 제목은 최대 30자, 평점은 1~5의 숫자(0.5단위로 부여 가능함),
    감상평은 최대 2000자, 한줄평은 최대 100자, 이미지는 최대 10MB
3. 각 감상평은 감상평ID로 구분한다(감상평 ID가 PK 역할 수행)
4. 감상평ID는 YYMMDD00001 형식으로 생성 날짜와 5자리 숫자로 구성된다.  
5. 감상평ID는 중복될 수 없으며 최초 생성 시 
   현재 날짜 YYYYMMDD + 현재 날짜의 마지막에 생성된 감상평의 ID + 1로 발번된다. 
   (동시 저장 시 경쟁 조건을 막기 위해 감상평ID 발번은 Supabase Database의 트리거/함수에서 원자적으로 처리한다)
6. 최초 생성되는 감상평ID의 숫자부분은 00001이다. 
7. 감상평 작성 화면에서 각각의 데이터를 입력한다. 
8. 저장 버튼을 클릭하면 Supabase Database의 `reviews` 테이블에 저장된다. 
9. 감상평은 작성한 로그인 사용자(user_id)와 연결되어 저장되며, 본인이 작성한 감상평만 조회/수정/삭제할 수 있다. (Supabase RLS로 제어)
10. 이미지는 10MB까지 저장 가능하며, Supabase Storage 버킷(`review-posters`)에 업로드하고 DB에는 이미지 경로만 저장한다. 
11. 이미지가 10MB 초과하면, 저장 불가 알림창이 표시된다. 
12. 이미지가 표기되는 프레임을 클릭하면 이미지를 로컬에서 불러올 지 API를 통해 불러올지 
선택하도록 하는 선택 창이 표시된다. 
13. 이미지를 로컬에서 불러올 경우, 파일 경로를 선택하여 업로드한다. 
14. API를 통해 이미지를 불러올 경우, TMDB API에서 영화를 검색할 수 있는 레이어가 생성되고,
    영화제목으로 이미지를 조회하여 선택할 수 있다. (감상평 작성_영화포스터 등록 팝업)
